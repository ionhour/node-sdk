# Ionhour Node SDKs

Read-only mirror of the Ionhour Node.js SDK packages, published to npm
from the private monorepo. Issues are welcome here; pull requests are
ported upstream by the maintainers.

| Package | Folder | Install |
|---|---|---|
| [`@ionhour/core`](https://www.npmjs.com/package/@ionhour/core) | [`core/`](./core) | `npm install @ionhour/core` |
| [`@ionhour/nestjs`](https://www.npmjs.com/package/@ionhour/nestjs) | [`nestjs/`](./nestjs) | `npm install @ionhour/nestjs` |
| [`@ionhour/express`](https://www.npmjs.com/package/@ionhour/express) | [`express/`](./express) | `npm install @ionhour/express` |

All three release together as one fixed version. Docs:
<https://docs.ionhour.com> · Agent index: <https://ionhour.com/llms.txt>
